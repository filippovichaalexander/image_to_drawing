The Right Strategy: Layered Approach
Instead of one model to rule them all, build two separate specialized models:

Model 1: Floor Plan Parser (walls, doors, windows, stairs)
Train on: CVC‑FP (122) + R2V (800) + part of CubiCasa5K (wall/window classes only)

Why:

These datasets are compatible – all have walls/doors/windows

Total ~1,000 images – fast to train, good quality

Enough to build a robust parser

What you get:

Accurate wall detection

Door and window positioning

Room segmentation (from CubiCasa5K if needed)

Model 2: Photo-to-Plan Aligner (cross-view matching)
Train on: C3 (90,000 paired images) – separate model

Why:

C3 is a completely different task (photo ↔ plan alignment)

Uses different architecture (Siamese networks, feature matching)

Should not be mixed with segmentation model

What you get:

Ability to match a photo to the right spot on the plan

Automatic orientation correction

Window/facade validation

def _extract_full(cleaned_images: list[Path]) -> dict[str, Any]:
    # Load trained YOLO model (CVC-FP + R2V + CubiCasa walls)
    model = get_floorplan_model()
    
    # Predict on each image
    results = model.predict(cleaned_images, imgsz=640, conf=0.3)
    
    # Convert masks to geometry format
    geometry = parse_yolo_results(results)
    
    # If photos exist, align and validate openings
    if self.photo_paths:
        aligner = get_c3_model()
        geometry = aligner.validate_openings(geometry, self.photo_paths)
    
    return geometry

Should I use all datasets?	NO – use CVC-FP + R2V for your main model
What about CubiCasa5K?	Use only wall/door/window classes – skip furniture
What about C3?	Separate model – use for photo alignment, not segmentation

Focus on quality over quantity. A well-trained model on 1,000 diverse plans beats a confused model on 90,000 mismatched ones.
