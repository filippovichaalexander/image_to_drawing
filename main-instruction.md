ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)Разработка веб-приложения автоматической векторизации и корреляции архитектурных чертежей и фотографий в формат DWG (ГОСТ)1. ОБЩИЕ СВЕДЕНИЯ И ЦЕЛЬ ПРОЕКТАЦель проекта: Создание высокопроизводительного, интуитивно понятного веб-приложения на языке Python для автоматизации работы архитекторов-реставраторов.Приложение должно принимать грязные сканы/изображения чертежей (планы, разрезы, фасады) и фотографии объекта, очищать их с помощью ИИ, распознавать геометрию и текстовые размеры, проводить кросс-валидацию данных между листами и генерировать скоррелированный пакет чертежей в формате .dwg / .dxf со строгим соблюдением требований ГОСТ 2.307-2011 [также известных как СПДС].2. БИЗНЕС-ЛОГИКА (USER FLOW)Пользовательский сценарий минимизирует количество действий со стороны человека:Загрузка данных: Пользователь заходит на минималистичную веб-страницу и загружает файлы методом Drag-and-Drop в два пула: «Чертежи» (обязательно) и «Фотографии здания» (опционально).Инициализация эталона (Опционально/Защита): Если ИИ не уверен в качестве автоматического масштабирования, система просит пользователя: «Введите реальную длину любого контрольного отрезка на главном плане (в мм)».Фоновая обработка: На сервере запускается изолированный пайплайн (очистка ➔ сегментация ➔ OCR-анализ ➔ фотограмметрия ➔ кросс-валидация ➔ CAD-генерация). Пользователь видит лаконичный прогресс-бар статуса.Интерактивный просмотр (WebGL): По окончании обработки на экране разворачивается 2D-окно просмотрщика. Пользователь может переключать слои (стены, размеры, оси), масштабировать чертеж колесиком мыши и проверять корректность стыковки.Экспорт: Пользователь нажимает одну кнопку «Скачать пакет DWG» и получает готовые структурированные файлы.3. Технологический стек:Frontend UI & Backend core: FastHTML (генерация быстрого, легковесного интерфейса без Node.js/React).Чертежный просмотрщик в браузере: PixiJS или dxf-viewer (JS библиотека, встраиваемая через FastHTML компонент, использующая WebGL для отрисовки векторов на стороне клиента).ИИ & Компьютерное зрение: PyTorch, OpenCV (математика изображений), YOLOv8-seg (сегментация), PaddleOCR (распознавание текста чертежей).Генерация CAD-файлов: ezdxf (создание структуры слоев, стилей текста и примитивов AutoCAD).4. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ И ИИ-ПАЙПЛАЙНОбработка каждого запроса должна строго делиться на 5 изолированных этапов:Этап 1. ИИ-очистка и восстановление (Image De-noising)Система должна автоматически устранять артефакты сканирования: замятия бумаги, блеклость туши, зернистость, серый фон.Применяется модель фильтрации на базе ControlNet (Canny/Tile) или предобученная сверточная сеть. Результат: бинарное черно-белое изображение высокого контраста.Этап 2. Распознавание геометрии и текста (Векторизация)Поиск стен и проемов: YOLOv8-seg изолирует замкнутые контуры несущих стен и перегородок, формируя массив координат \([x, y]\).Поиск размерных цепочек: Модель находит засечки и выносные линии.Чтение номиналов и осей: PaddleOCR считывает текстовые значения размеров внутри цепочек и буквенно-цифровые обозначения координационных осей (например: "Ось А", "Ось 1").Этап 3. Обработка фотографий здания (Гибридный режим)Опция А (Выравнивание): На основе алгоритма OpenCV Perspective Transform (или SIFT-дескрипторов) фотографии фасадов, сделанные под углом, трансформируются в плоский ортофотоплан.Опция Б (Уточнение деталей): Модель сегментации анализирует выровненную фотографию высокого разрешения, определяет точный паттерн оконных переплетов и декора (лепнины) и обогащает базу данных элементами, которые были размыты на скане чертежа.Этап 4. Кросс-валидация и многовидовая корреляция размеровАлгоритм на Python сопоставляет данные со всех загруженных листов по координационным осям.Перенос высот: Привязка окон и карнизов по высоте (координата \(Z\)) берется с Разреза/Фасада и автоматически проецируется на План (координаты \(X, Y\)).Матрица голосования размеров: Если на Плане комната распознана как 3000 мм, а на Разрезе как 3005 мм, математический модуль принудительно округляет и выравнивает размер до нормативного строительного модуля по ГОСТ (кратность 10/50/100 мм).Этап 5. Генерация файла DWG по ГОСТ 2.307-2011 через ezdxfСборка файла кодом должна происходить по жестким правилам:Слои: Разделение объектов по слоям (01_Стены_Капитальные, 02_Перегородки, 03_Оси, 04_Размеры_ГОСТ, 05_Окна_Двери).Размерные линии: Отрисовка выносных линий с отступом ровно 10 мм от объекта. Засечки длиной 2–4 мм под углом 45 градусов. Шрифт текста — ISOCPEUR (или аналогичный векторный ГОСТ-шрифт), расположенный строго по центру над размерной линией.5. НЕФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ (ПРОИЗВОДИТЕЛЬНОСТЬ И UI)Скорость интерфейса: Время ответа UI (фронтенда FastHTML) на клики пользователя — не более 100 мс.Производительность ИИ: Время полной обработки пакета из 3 чертежей и 2 фотографий не должно превышать 15-20 секунд (при работе на GPU-сервере).Просмотрщик: Плавный зум (минимально 60 FPS) при отображении до 50 000 векторных линий в браузере за счет WebGL.Адаптивность: Интерфейс должен корректно открываться на любых экранах, иметь темную/светлую тему оформления и понятные подсказки для каждого шага.План реализации MVP проекта:Разработка UI-каркаса на FastHTML с зонами загрузки файлов.Написание скрипта очистки сканов (OpenCV + фильтры).Интеграция PaddleOCR и YOLOv8-seg для получения первого JSON с координатами стен и цифрами размеров.Разработка математического модуля сборки чертежа через ezdxf (размеры по ГОСТ).Написание алгоритма стыковки планов и фасадов по координационным осям.Подключение модуля фотограмметрии для обработки фотографий.С чего вы хотите начать реализацию этого ТЗ? Какие стандарты РФ необходимо заложить в кодПриложение должно использовать следующие актуальные нормативные документы:ГОСТ Р 21.101-2020 «СПДС. Основные требования к проектной и рабочей документации»: Регулирует общие правила оформления, состав чертежей, названия и структуру слоев AutoCAD.ГОСТ 2.307-2011 «ЕСКД. Нанесение размеров и предельных отклонений»: Задает геометрию размерных линий (расстояния 10 мм, засечки под 45°, стрелки).ГОСТ 2.303-68 «ЕСКД. Линии»: Определяет толщину и тип линий (сплошная толстая для капитальных стен — 0.6–1.5 мм, тонкая для размеров и штриховок — 0.2–0.5 мм, штрихпунктирная для осей).ГОСТ 2.304-81 «ЕСКД. Шрифты чертежные»: Регулирует начертание букв и цифр. Необходима, определенным этапом -  Автоматическое построение рамки и заполнения штампа (ГОСТ Р 21.101-2020)Согласно ГОСТ Р 21.101-2020, каждый чертеж должен иметь внешнюю рамку, внутреннюю рамку (отступы: 20 мм слева для подшивки, по 5 мм сверху, снизу и справа) и основную надпись (штамп) по Форме 3 (размер 185х55 мм) в правом нижнем углу.1. Алгоритм работы модуля в приложении:Определение формата: ИИ на основе габаритов распознанного здания вычисляет необходимый формат листа (А4, А3, А2, А1) и его ориентацию (альбомная/книжная).Сбор метаданных из интерфейса (UI FastHTML): Перед генерацией пользователь заполняет простую форму (Название объекта, Шифр, Стадия проекта: "Р" или "П", ФИО разработчика/проверил).Генерация геометрии через ezdxf: Скрипт строит внешние границы, внутреннюю рамку и сетку таблицы штампа строго в миллиметрах в масштабе 1:1 в пространстве листа (Layout) или пространства модели.Текстовое заполнение: Программа вставляет строки в нужные ячейки таблицы, используя шрифт ISOCPEUR с выравниванием по центру ячейки.

import ezdxf

def add_gost_stamp_and_frame(doc, layout, format_name="A3", orientation="landscape", metadata=None):
    """
    Создает рамку и заполняет штамп по Форме 3 ГОСТ Р 21.101-2020.
    Размеры для А3 альбомного: 420 х 297 мм
    """
    if metadata is None:
        metadata = {
            "company": "Мосреставрация",
            "object_name": "Усадьба А.Б. Петрова, XIX в. Корпус 1",
            "sheet_name": "План 1-го этажа в осях 1-10",
            "code": "026-2026-АР",
            "stage": "Р",
            "sheet_num": "3",
            "checked_by": "Иванов И.И.",
            "drawn_by": "Петров П.П."
        }

    # Размеры листа А3 (в мм)
    w, h = 420, 297
    
    # 1. Создаем слой для оформления
    if "00_Оформление" not in doc.layers:
        doc.layers.new("00_Оформление", dxfattribs={"color": 7, "lineweight": 40}) # 0.4 мм для рамки
    if "00_Текст_Штампа" not in doc.layers:
        doc.layers.new("00_Текст_Штампа", dxfattribs={"color": 7, "lineweight": 20}) # 0.2 мм

    # 2. Отрисовка внутренней рамки (ГОСТ: 20 мм слева, по 5 мм с остальных сторон)
    x_min, y_min = 20, 5
    x_max, y_max = w - 5, h - 5
    
    # Рисуем рамку
    layout.add_lwpolyline(
        [(x_min, y_min), (x_max, y_min), (x_max, y_max), (x_min, y_max), (x_min, y_min)],
        dxfattribs={"layer": "00_Оформление"}
    )

    # 3. Построение штампа (Форма 3: 185 x 55 мм) в правом нижнем углу
    # Левый нижний угол штампа:
    sx, sy = x_max - 185, y_min
    
    # Внешний контур штампа
    layout.add_lwpolyline(
        [(sx, sy), (x_max, sy), (x_max, sy + 55), (sx, sy + 55), (sx, sy)],
        dxfattribs={"layer": "00_Оформление"}
    )
    
    # Добавление основных разделительных линий таблицы штампа (пример ключевых граф)
    layout.add_line((sx, sy + 15), (x_max, sy + 15), dxfattribs={"layer": "00_Оформление"}) # Линия Шифра
    layout.add_line((sx + 50, sy), (sx + 50, sy + 55), dxfattribs={"layer": "00_Оформление"}) # Раздел ФИО/Подпись
    layout.add_line((x_max - 35, sy), (x_max - 35, sy + 15), dxfattribs={"layer": "00_Оформление"}) # Стадия/Лист
    
    # 4. Заполнение текстом (ГОСТ 2.304-81, шрифт ISOCPEUR)
    # Шифр проекта (крупный шрифт по центру верхней графы)
    layout.add_text(
        metadata["code"], 
        dxfattribs={"layer": "00_Текст_Штампа", "style": "GOST_ST", "height": 5.0}
    ).set_placement((sx + 92.5, sy + 35), align=ezdxf.enums.TextEntityAlignment.CENTER)

    # Название объекта реставрации
    layout.add_text(
        metadata["object_name"], 
        dxfattribs={"layer": "00_Текст_Штампа", "style": "GOST_ST", "height": 3.5}
    ).set_placement((sx + 55, sy + 10))

    # Стадия
    layout.add_text(
        metadata["stage"], 
        dxfattribs={"layer": "00_Текст_Штампа", "style": "GOST_ST", "height": 3.5}
    ).set_placement((x_max - 30, sy + 5), align=ezdxf.enums.TextEntityAlignment.CENTER)
    
    # Разработчики (графы слева)
    layout.add_text(f"Разраб.  {metadata['drawn_by']}", dxfattribs={"layer": "00_Текст_Штампа", "style": "GOST_ST", "height": 2.5}).set_placement((sx + 2, sy + 45))
    layout.add_text(f"Пров.     {metadata['checked_by']}", dxfattribs={"layer": "00_Текст_Штампа", "style": "GOST_ST", "height": 2.5}).set_placement((sx + 2, sy + 38))
